# Hoshizora Launcher 🌌

![Logo](https://kydqhl70pt.ufs.sh/f/SbIOO8eHSfnAjWRps8cI4m1X5FZ3rBMwEtRo7N8pfHzly2gd)

_"Find the star within your heart"_

Hoshizora Launcher is a magical, lightweight Minecraft launcher inspired by Japanese aesthetics and the vast, glittering cosmos. Immerse yourself in your Minecraft world and discover the star that shines inside you. ✨

## 🌟 Features

- 🌙 **Elegant Japanese-inspired design** with serene night sky motifs  
- 🎮 **Support for official and modded Minecraft versions**  
- ⚡ **Quick setup and instant play**  
- 🌌 **Light and dark themes** evoking a starry night  
- 🛠️ **Profile management** for different versions and mods  
- 🔄 **Automatic launcher updates**

---

## 🚀 Installation

1. Download the latest version [here](https://github.com/MOLf1i/Hoshizora-Launcher/releases).  
2. Open the file and launch **Hoshizora Launcher**.  
3. Log in with your Minecraft account.  
4. Select your game version and click **Play**.  

---

## 🌌 Customization

- Change themes and backgrounds inspired by the starry sky  
- Add mods and resource packs  
- Adjust graphics and FPS settings for smooth gameplay
